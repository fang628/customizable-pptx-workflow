# 生图提示词口径（阶段 2.1／2.2）

本文件统一定义整页生成的提示词要求，其他阶段引用本文件。提示词是画图指令，设计决策先按[设计判断与检查提示](../../../shared/design-principles.md)确定；不把审美建议改写成普遍硬要求。

## 编写前必读

每轮编写或修订整页提示词前，重新读取本文件、当前生成阶段要求、比例契约及本轮相关设计／页型／分块规范，并核对当前页的最新文案、图片计划与已确认风格。图生图返工同样执行；不凭记忆编写，生成前脚本自检不能替代此次阅读。读取范围统一见[三个必读时点](../../../shared/operations.md#三个必读时点)。

本文“无文本框”指无可见框体或无填充描边，最终文字仍须放在独立可编辑的PowerPoint原生文本对象中；不表示把文字烘焙进图像。

从设计稿排版树提取文案时，去掉仅为阅读而添加的 Markdown 加粗包裹，保留原始文字；列表缩进与空间归属继续保留。设计稿中的文案加粗不等于画面字重指令，实际字重按已确认设计说明表达。

## 九项分点结构

提示词必须用 Markdown 顶层列表组织以下九项要求，项名可加粗；“排版要求”内部必须按下节的实际分块树逐层嵌套，不能仅把九项写成平铺段落：

1. **比例要求**：页型与主题描述、16:9（1920×1080）；页面归属只在任务元数据中绑定。
2. **内容要求**：该页设计稿的每段最终文字及语义角色（标题／小标题／正文／注释）。文字只用于表达内容与语义角色，预览不要求逐字排印，成品原生文字必须准确。图片旁图注按设计稿；封面／目录AI元素底图不新增图注，提示词不为其安排caption文字、图注框或说明标签；并列文本框采用“小标题＋正文”时，逐框带入设计稿的小标题和正文，区分语义层级，同组小标题样式一致。多段并列文字必须带入统领整组的小标题，已有标题确实概括整组时可复用，不能只归到某一条；各并列段落仍分别排入独立文本框。未规划小标题时不自行补写：先回到设计稿补齐并同步定稿，再带入提示词；目录条目包含标号，不额外添加设计稿未写的分标题。
3. **排版要求**：说明实际宏观与微观分块、特殊形态及组合、内容归属、相邻关系和阅读顺序。文字条目仅写具体文案、文段类型、位置和文本关系；多段并列文字逐段作为独立文本框，并安排统领整组的小标题。原有特殊分块形式须交代，但可按内容采用创意变体，不照搬参考图；轮廓、曲率、局部比例和间距留给模型合理发挥。图片与其他图形逐项交代内容、位置和必要结构，箭头写清真实起止关系。框形与配色集中到风格要求，不在文字条目或父分块重复。
4. **底图与配图要求／图片占位框比例**：封面与目录使用“底图与配图要求”，写明原底图主体、保留与调整内容；封面和目录尽量采用不同的主题对象，目录优先选择与封面不同的另一对象；提示词写清实际对象，不只让同一对象换场景、视角或裁切，并保持同一视觉风格，差异以设计稿实际选择为准；描述文字和图形元素如何在底图上构建，不要求图片占位框；执行[原底图构建契约](../../../shared/preview-contract.md#封面与目录的原底图构建)。其他页型使用“图片占位框比例”：逐张写图片内容名称、图片位比例和所在分区；每页必须说明至少一处相关配图；生成的非事实性主题图或示意图直接描述其内容与位置，登记事实图使用占位框。不能以“无占位图”省略每页配图要求。事实图只画与背景可分辨的平坦占位块，占位块默认不写字；确需区分时只写简短内容说明；占位框宽高比不能改变，不拉伸、不变形。其他页型2.1 保留占位块，2.2 本地插入登记原图后再提交批准。
5. **风格要求**：必须含“简约要求”和“紧密排版要求”两个非空嵌套子项，不再将它们单列为顶层项；简约针对文本框干净克制，紧密排版保证分组紧凑、正文空间充分、不靠缩小文字。风格说明还须明确预览图的实际排版要有创意，给生图模型保留分块组合、轮廓与局部构图的合理发挥空间，不另列创意条目；简要说明气质、配色、背景处理及特殊分块的造型语言；文本框形状／无框、填充、描边与文字层级按角色或适用范围集中说明一次，局部样式差异也在此说明。保证有填充的框底与局部背景有适度色差、框高适配文字和必要内边距；不限定机械一致的轮廓或细节。特殊分块在本项交代整体语言，在排版树交代实际结构，互补而不重复全文。材质、光影和装饰按实际需要补充，留出创意空间，可读性与内容逻辑优先。
6. **进度条要求**：按 content.json 的 progress_bar 决定显示；启用时写全部 sections 标题、当前小节突出与段间色差；标题／目录／致谢页写“无进度条”。


7. **可读性要求**：单独强调文字清晰、层级分明、对比充分，并优先保障正文空间。
8. **视觉关系要求**：单独强调分组、连接、箭头与图文对应反映真实关系，不为了创意改变内容逻辑。
9. **原图保真要求**：单独强调事实原件不重画、不拉伸，保留主体与关键信息；无事实原件时明确不适用，仍保留底图已确认视觉内容。

## 底图复杂度与视觉主次

新生成或重新设计底图时，每条实际发送的底图提示词必须逐字包含“不要过于复杂，不要抢夺视觉中心”，不能用近义表述替代或只写进任务摘要；按[底图生成的复杂度与视觉主次](../../../shared/design-principles.md#底图生成的复杂度与视觉主次)区分封面、目录与内容页用途。整页预览在“风格要求”或“底图与配图要求”中落实主次：文字区保持平静，不新增压过标题、导航、正文或证据的纹理、强光效和装饰。该要求独立于文本框简约，不要求把底图一律改成纯色。

沿用已确认复杂底图时，先通过构图、局部承载或适度遮罩保障阅读；不自动重生成，也不因文本框简约抹去底图主体与必要细节。确实存在抢夺视觉中心的问题时针对干扰区域修订。

## 紧凑排版、创意与学术答辩风格

“简约要求”只约束文本框的填充、描边和框内装饰，不约束三类AI底图的复杂度；新生成和图生图修改都不得仅为满足该条而简化原底图。复杂底图影响文字阅读时，优先通过干净的文本框承载、局部遮罩或位置调整改善对比，保护原底图主体与整体视觉信息。学术答辩的专业气质也不等于把复杂底图改为简单色块。

每页提示词必须在“风格要求”下明确写出“简约要求”和“紧密排版要求”两个非空Markdown子项，二者必不可少，不能只隐含在风格形容词或排版树中。创意不另设条目，在风格说明中明确实际排版应有创意，并给模型留出实现空间。各项明确画面目标，排版树记录具体实现；不要重复抄写整棵树。阶段2.1／2.2的新生成与图生图修订均适用。

- **紧凑排版与文字空间**：在风格要求下的“紧密排版要求”子项中明确画面紧凑、分组清楚、有效空间集中用于文字和相关图片；根据实际文案体量分配区域，给正文足够宽度与排布空间，保证投影阅读清晰。不能一边保留无用途的大块空白或让装饰、主视觉占据过多空间，一边压窄文字区域、把正文缩得过小。保留必要的内边距、组间间距和阅读留白；紧凑不等于拥挤。空间不足时先调整分块、图文比例和装饰范围，不靠缩小文字解决，也不擅自删改定稿文案。提示词只描述相对层级与空间关系，不写具体字号、框尺寸或密度阈值。
- **有内容依据的创意设计**：创意指预览图的实际排版效果，不是单列一个“创意要求”条目，也不是只写一个形容词。风格说明应要求实际排版有创意，允许模型在已确认的内容归属、阅读顺序与图文关系内，自主选择或优化分块组合、轮廓、曲率、衔接与局部构图，不逐项锁死实现方式。积极采用适合内容的特殊分块与组合，继续满足全篇特殊分块页数严格过半；生成后实际看图判断创意是否落实，不能以提示词出现“创意”二字替代审查。可读性、内容逻辑和原图保真优先，避免装饰堆叠或挤压正文。
- **学术汇报／答辩的条件性风格**：需求确认属于学术汇报或学术答辩时，在风格要求下的“简约要求”子项中明确简约学术、文本框色块干净，框内尽量使用均匀平整填充，尽量不要使用渐变；渐变可用于文本框之间或装饰色块之间的衔接，不干扰文字区域。分标题采用有底色的文本框时，与正文文本框应有可辨认的适度色差，以区分层级，不设固定色值或阈值，不要求无框文字额外套框。框内避免纹理、颗粒、污渍、强高光与繁复图案；保留实际排版的创意和底图必要主题细节。创新创业项目不套用上述渐变与分标题框色差要求，即使采用项目答辩形式也按创新创业用途判断；按已确认风格自由设计，并保证可读性与内容逻辑。具体判断见[场景性文本框处理](../../../shared/design-principles.md#学术与创新创业场景的文本框处理)。

学术场景可在风格要求下使用以下子项；创新创业项目不照抄：

> 简约要求：文本框内部尽量不要使用渐变，优先干净平整的填充；文本框或装饰色块之间可以有渐变衔接。分标题文本框与正文文本框保持可辨认的适度色差，层级清楚。

可按本页实际方案使用的提示词措辞：

```markdown
- **风格要求**：沿用已确认方向，明确以下两项要求。 预览图的实际排版要有创意；模型可在内容关系与阅读顺序内自主优化分块组合、轮廓和局部构图，不逐项锁死细节。
  - **简约要求**：简约仅针对文本框：色块干净、边缘清楚、框内装饰克制；封面、目录和内容页三类底图保留原有主体、层次与细节，复杂底图不做简约化。
  - **紧密排版要求**：分组紧凑有序，减少无用途留白，给文字足够宽度与空间，不以缩小正文换取松散构图。
- **可读性要求**：文字层级清楚、对比充分，正文空间充足；复杂底图通过干净框底和位置安排保障阅读，不为构图或装饰缩小文字。
- **视觉关系要求**：分组、箭头及图文对应准确表达真实内容关系，阅读顺序明确；不为创意制造错误因果或错误归属。
- **原图保真要求**：事实照片和数据图不交给模型重画，不拉伸、不替换为近似图；本地等比插入并保留关键主体、坐标轴、图例和单位。无事实原图时说明不适用，底图仍保留已确认主体与细节。
```

上述示例演示风格要求内的两个必填子项及三个独立强调项；完整提示词仍须包含九项要求和实际嵌套分块树。生成后逐页检查是否存在“画面松散但文字拥挤或过小”、创意描述未落实、学术答辩文本框色块不干净等问题，针对具体问题修订。可读性优先，不新增纯审美数值否决条件。

## 可读性、视觉关系与原图保真的独立强调

每页提示词还必须独立填写“可读性要求”“视觉关系要求”“原图保真要求”三个Markdown顶层列表项，不能仅在内容要求或排版树中顺带提及。这三项保留为独立顶层强调项；简约与紧密排版合并在风格要求中，仍为必填子项；每项保持简短可执行，不抄写整份规范。

- **可读性优先**：复杂底图可以保留复杂度；以干净文本框、局部承载和位置安排保证文字清楚，不以简化底图或缩小正文作为默认办法。紧凑与创意不能牺牲对比、层级及投影阅读，必要留白保留。
- **视觉关系准确**：对应当前页实际的并列、因果、递进或流程关系说明分组与阅读顺序；箭头仅连接有依据的对象，图片紧邻所支持的内容，不能引入虚假关系。没有连接需求时不强加箭头。
- **原图保真**：阶段2.1按页型处理底图和占位，阶段2.2在批准前本地插入登记事实原件，不把事实图交给模型重画。不拉伸，不生成替代证据；允许按已确认计划适配或遮罩边缘，但主体、图中文字、坐标轴、图例、单位和关键细节完整。无事实原件时该条明确说明不适用，不要求创建占位框或虚构证据；封面／目录继续在原底图基础上构建，不新增底图图注。

生成前校验只检查独立条目与非空说明，不能自动证明清晰度、关系准确或实际保真；生成后逐页实际查看并核对设计稿和登记原件。

## Markdown 嵌套列表与实际分块树

阶段2.1／2.2的新生成和图生图修订提示词必须使用 Markdown 语法，九项要求作为顶层列表项；“排版要求”内部用缩进子列表表达画面实际的空间归属：**宏观分块 → 微观子分块 → 更深层子分块（实际存在时继续嵌套）→ 文字及其文本框、图片、装饰等具体元素**。同级列表表示并列区域或并列对象，子列表表示属于其父分块，不能把空间层级写成一串平级说明或仅列素材类别。

- 每个分块先说明位置、边界形态、所承载内容、与相邻分块的关系及阅读顺序，再嵌套它的子分块和元素。嵌套深度由实际版式决定；已有子分块必须展开，不为凑层数虚构分区。
- 每段文字及其独立文本框放在实际所属分块下，只写具体文案、文段类型、位置和文本关系；并列段落逐项展开，由共同小标题统领。框形、填充、描边和文字配色只在风格要求中按角色说明一次。
- 图片、图标、装饰和编号底座放在实际所属分块下，逐项写内容、形态、样式、叠放和邻接关系。框内装饰归入对应文本框，不把它与整页装饰混列；跨分块箭头或装饰归入共同父分块，写清覆盖区、连接对象和前后层次。
- “内容要求”写页面语义与阅读目标；完整文案在排版树的对应文字条目中逐段出现，不必另抄一次平级清单。“底图与配图要求／图片占位框比例”集中说明底图或原件处理规则；具体图片位仍嵌套在所属分块中。“风格要求”描述共用视觉语言，文本框局部样式差异也集中在风格要求中按适用范围说明，不逐框重复。特殊分块的造型语言在风格要求概括，实际形态和空间关系在分块树展开；曲率、轮廓等可灵活发挥，不逐个锁死细节。
- 使用空格缩进，按 Markdown 列表层级对齐；API 的 prompt 字符串保留真实换行和缩进，不压成单行。不把整个提示词包在代码围栏里；本文件示例的围栏仅用于展示写法。分块名和元素名使用内容名称与位置描述，不写内部编号、具体坐标、文本框尺寸或字号。

示例（结构演示，按本页设计稿替换内容和分块）：

```markdown
- **可读性要求**：文字层级清楚、对比充分，正文空间充足；复杂底图通过干净框底和位置安排保障阅读，不为构图或装饰缩小文字。
- **视觉关系要求**：分组、箭头及图文对应准确表达真实内容关系，阅读顺序明确；不为创意制造错误因果或错误归属。
- **原图保真要求**：事实照片和数据图不交给模型重画，不拉伸、不替换为近似图；本地等比插入并保留关键主体、坐标轴、图例和单位。无事实原图时说明不适用，底图仍保留已确认主体与细节。
- **比例要求**：内容页，16:9（1920×1080）。
- **内容要求**：先说明研究方法，再展示结果，最后总结结论。
- **排版要求**：上方标题区，下方左侧方法区与右侧证据区；由上到下、由左到右阅读。
  - **上方标题区**：保持清晰阅读背景。
    - **标题文字及其文本框**：位于上方，左对齐。
      - 文案与角色：“研究方法与结果”，页面标题。
  - **下方主体分块**：方法区与证据区由斜切边界分隔；方法在左、证据在右，边界倾向明确，具体斜率可按文字空间调整。
    - **左侧方法分块**：两段文字上下并列，由同一小标题统领。
      - **统领小标题及其独立文本框**：位于两段正文上方。
        - 文案与角色：“方法概览”，小标题，统领数据处理与验证两项。
      - **上部方法子分块**：说明数据处理。
        - **文字及其独立文本框**：位于小标题下方，第一项并列分点。
          - 文案与角色：“统一数据口径后开展比较。”，正文。
      - **下部方法子分块**：说明验证。
        - **文字及其独立文本框**：位于第一项下方，与其并列。
          - 文案与角色：“通过独立样本检验结果。”，正文。
    - **右侧证据分块**：图片在上，说明在下。
      - **上部图片区**：实验结果图，图片位比例4:3；画与背景可区分的无字占位块，按此比例画，不拉伸、不变形。
      - **下部说明区**：紧随图片，说明图片内容。
        - 文案与角色：“结果对比”，图注。
    - **跨区连接箭头**：由方法区指向证据区，表达验证关系，置于两区间隙，不穿过文字。
- **图片占位框比例**：事实图仅预留占位块；完整预览批准前在本地插入登记原图。
- **风格要求**：沿用所给大图的深蓝与青蓝同一套配色；背景渐变与细微主题纹理集中于外缘，文字区平静；正文文本框统一采用干净浅蓝填充、细青色描边的圆角矩形，与局部背景有适度色差，框高适配文字；标题、小标题与图注无可见框体，标题字重突出。以斜切分块体现方法与证据的呼应，保留边界轮廓与局部间距的创意空间，优先保证正文阅读。 预览图的实际排版要有创意；模型可在内容关系与阅读顺序内自主优化分块组合、轮廓和局部构图，不逐项锁死细节。
  - **简约要求**：简约仅针对文本框：色块干净、边缘清楚、框内装饰克制；封面、目录和内容页三类底图保留原有主体、层次与细节，复杂底图不做简约化。
  - **紧密排版要求**：分组紧凑有序，减少无用途留白，给文字足够宽度与空间，不以缩小正文换取松散构图。
- **进度条要求**：按本页已确认导航写全小节标题，突出当前小节。
```

## 全部文本框与图形元素的逐项说明

生成页面预览时，不能只写“按设计稿排版”或概括几个大分区。提取当前页所有可见元素，按分区与阅读顺序逐项写清，统一样式可先描述一次，但每个对象的内容、位置关系和独立性都须保留：

- **每个文本框**：排版树只写具体文字、文段类型、所属分区、位置和文本关系，并明确独立排布；多段并列文字必须有统领整组的小标题。文本框形状、颜色与共用样式集中在风格要求一次说明，局部差异也按角色或范围集中说明，不能逐框重复，不能合并并列段落。
- **每个其他图形元素**：说明形态和用途、颜色／填充／描边、方向或曲率、相对大小、大致位置及与文字、图片或其他图形的关系；需要叠放、贴合、遮罩或出血时写清。覆盖主视觉、图标、圆环、节点、装饰纹样、分区色块、编号底座及导航分段，不用“若干装饰”代替设计稿已经规划的对象。
- **箭头和连接线**：逐条写连接的真实内容名称、起止对象、方向、路径走向和连接作用；不使用内部元素编号，也不凭装饰引入错误因果。
- **分区与图片位**：用文字说明实际分区数量、边界走向、嵌套或组合、阅读顺序及色差／间距；每处配图说明内容、图片位比例和位置。其他页型的事实图片按登记原件等比占位与本地插入；封面／目录按原底图构建契约，不要求占位框；不让模型重画事实图。

若同类装饰形成规则阵列，可按一组描述数量或排列模式、成员形态与覆盖区域，不必给每个点单独起名；关键独立对象仍逐项说明。这些是语义和相对关系描述，不写具体坐标、文本框尺寸或字号；内部编号只留在本地元数据。风格参考图不能代替上述元素描述，生成后按设计稿逐项实际看图检查遗漏、误合并和样式偏差。

## 风格说明的具体程度

风格说明可以简略，通常用2–4句或几个短子项即可；这是写作建议，不设句数限制。写清本页实际需要的视觉特征，不必逐项展开材质、光影、纹理和字体细节。

- **主要信息**：整体气质、主辅配色及用途、背景与文本框的处理。字体只说明有必要区分的层级或字重，文本框形状、填充、描边与角色层级集中在本项一次说明，不在排版树重复；同时概括原有或选定的特殊分块造型语言，允许符合内容关系的变体。
- **继承与差异**：沿用已确认方向时，简短说明继承的配色和视觉语言，再写本页实际差异；保留足以执行的关键信息，不只写“同风格”或“高级”。每次提交的提示词仍应自足，不假设模型能读取本地全篇约定。
- **可选效果**：仅在本页实际采用时补充材质、光影或主题装饰；允许无装饰、平整色面和克制处理，不为写详细而增加特效。学术汇报／答辩须明确简约学术、框内尽量不用渐变及分标题框与正文框的层级色差；允许框间或装饰色块间渐变，创新创业项目不套用这些场景要求。

示例：

> 风格要求：沿用所给底图的深蓝与青蓝同一套配色，采用简约学术风格。背景平静，文本框为干净平整的浅蓝色块，与背景有适度色差；标题字重突出，正文清晰。保留原底图主题细节与复杂度，以干净框底承载正文并保障阅读空间。

生成后若层级、主题表达或构图创意不足，针对缺失的分组、图文关系或主题特征补充描述；不因说明较短或画面克制而反复生图，不靠装饰堆叠替代设计。

## 内部编号不进入提示词

所有生图阶段的新生成与图生图修订提示词均不得包含内部页面、文本、图片、素材、参考页或任务编号，例如 S01、S03-BODY-01、GEN-001、RECON-001 等。即使附上“不要画编号”的否定句，也不要把实际编号写进提示词。不得把设计稿表格、元素清单、带编号的标题或素材文件名原样拼接给模型。

按“左侧问题卡片”“右侧实验结果图”“方法概览小标题”等内容名称、位置和语义角色描述元素；箭头用内容短语说明连接关系。内部编号与描述的映射保留在本地 JSON、提示词记录的元数据栏和账本中，与实际发送的 prompt 正文分开。整页任务用 page_id 绑定页面；兼容从任务 id 解析页面，不能再从提示词解析页面。

占位块默认无文字，需要文字时只用内容说明。用户确认的目录序号、步骤序号、公式编号、产品型号或样本名称属于实际内容，按定稿保留；不要把内部工程标签当作这些上屏内容。

生成前自检发现内部编号时直接退回提示词，先人工改成内容描述再提交，不静默删除，以免损坏科学内容或箭头逻辑。

## 禁写信息

**禁止在提示词中写元素具体坐标、文本框具体尺寸和字号**，包括 x／y、固定框宽高、像素位置与归一化坐标。画布尺寸、图片位比例和科学内容中的数字可以保留；字号仅留在设计稿，精确几何与轮廓点留在图片计划和重建规格。新生成与图生图修订同样遵守。

不写检查码、规则编号、审美阈值、机检条文或整份设计稿；每次只提取当前页。事实边界写进任务字段 factual_boundary，不堆成提示词长段。

## 参考图与素材

- 封面和目录使用该方向已确认原底图（hero-image／toc-image 或已登记替代底图），在原底图上构建；content／thanks 可参考 content-background，参考不意味着必须铺进成品，其背景形式与主视觉位置以设计稿为准。

- 可用已生成预览作内部参考；旧稿、照片等外部材料须登记并获准上传，数量遵守 referenceImageLimit。需要编辑事实图时在本地处理，不交给模型重画。

## 生成与修订

先dry-run自检供应商、任务与提示词，再execute；生成器检查九项顶层结构、风格要求中的两个必填子项及三个独立强调项、画布规格、部分内容／框形／比例／风格／导航描述与元数据一致性，不能自动证明所有对象均已描述或实际绘制。编写者须逐项对照设计稿检查元素描述完整，生成后逐页核对画面落实。每次生成后逐页看图，按设计判断检查逻辑、可读性与一致性。

返工把被退回的原页放入 references 或 edit_source，逐条写明保留什么、改什么，在原图基础上图生图修改；保留编辑谱系与哈希，不另起无来源的新图绕过返工。2.2 修订完成后重新本地插入登记原件并复看。
