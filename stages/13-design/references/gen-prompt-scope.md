# 生图提示词口径（阶段 2.1／2.2）

本文件统一定义整页生成的提示词要求，其他阶段引用本文件。提示词是画图指令，设计决策先按[设计判断与检查提示](../../../shared/design-principles.md)确定；不把审美建议改写成普遍硬要求。

## 编写前必读

每轮编写或修订整页提示词前，重新读取本文件、当前生成阶段要求、比例契约及本轮相关设计／页型／分块规范，并核对当前页的最新文案、图片计划与已确认风格。图生图返工同样执行；不凭记忆编写，生成前脚本自检不能替代此次阅读。读取范围统一见[三个必读时点](../../../shared/operations.md#三个必读时点)。

本文“无文本框”指无可见框体或无填充描边，最终文字仍须放在独立可编辑的PowerPoint原生文本对象中；不表示把文字烘焙进图像。

从设计稿排版树提取文案时，去掉仅为阅读而添加的 Markdown 加粗包裹，保留原始文字；列表缩进与空间归属继续保留。设计稿中的文案加粗不等于画面字重指令，实际字重按已确认设计说明表达。

## 十二项分点结构

提示词必须用 Markdown 顶层列表组织以下十二项要求，项名可加粗；“排版要求”内部必须按下节的实际分块树逐层嵌套，不能仅把十二项写成平铺段落：

1. **比例要求**：页型与主题描述、16:9（1920×1080）；页面归属只在任务元数据中绑定。
2. **内容要求**：该页设计稿的每段最终文字及语义角色（标题／小标题／正文／注释）。文字只用于表达内容与语义角色，预览不要求逐字排印，成品原生文字必须准确。图片旁图注按设计稿；封面／目录AI元素底图不新增图注，提示词不为其安排caption文字、图注框或说明标签；并列文本框采用“小标题＋正文”时，逐框带入设计稿的小标题和正文，区分语义层级，同组小标题样式一致。设计稿为整组并列文字规划了概括性小标题时，带入该标题及其对整组的归属关系，不能只归到某一条；各并列段落仍分别排入独立文本框。未规划小标题时不自行补写；目录条目包含标号，不额外添加设计稿未写的分标题。
3. **排版要求**：分块方式、阅读顺序、每段文字的文本框形状或“无文本框”、填充色和描边色。同级共用的样式描述一次，逐段保留文案与角色。多段并列文字逐段列为子列表，并明确每段使用独立文本框、不能合并为一个大文本框。有填充的框写清框底与所在区域实际背景的适度色差，填充色和描边色分别说明；配色判断按统一设计原则，不写固定色差阈值。说明本页实际选定的分区形态，允许与分块参考图不同；箭头写清起止、方向与连接内容。写明框高贴合文本、适量内边距、避免框内大片留白；为同尺度比较采用等高卡片时说明用途。框形与装饰只描述设计稿实际选择，不强求多样。
4. **底图与配图要求／图片占位框比例**：封面与目录使用“底图与配图要求”，写明原底图主体、保留与调整内容；封面和目录建议使用不同主体并保持同一视觉风格，差异以设计稿实际选择为准；描述文字和图形元素如何在底图上构建，不要求图片占位框；执行[原底图构建契约](../../../shared/preview-contract.md#封面与目录的原底图构建)。其他页型使用“图片占位框比例”：逐张写图片内容名称、图片位比例和所在分区；每页必须说明至少一处相关配图；生成的非事实性主题图或示意图直接描述其内容与位置，登记事实图使用占位框。不能以“无占位图”省略每页配图要求。事实图只画与背景可分辨的平坦占位块，占位块默认不写字；确需区分时只写简短内容说明；占位框宽高比不能改变，不拉伸、不变形。其他页型2.1 保留占位块，2.2 本地插入登记原图后再提交批准。
5. **风格要求**：按下节《风格说明的具体程度》简要写清整体气质、配色分工及背景与文本框处理；材质、光影和装饰仅补充实际采用项，不逐页展开所有维度。参考图与文字说明共同约束画面；配色距离只提示复看，合理浅深页可以保留。
6. **进度条要求**：按 content.json 的 progress_bar 决定显示；启用时写全部 sections 标题、当前小节突出与段间色差；标题／目录／致谢页写“无进度条”。

7. **简约要求**：独立强调文本框色块和框内装饰简约、干净；不要求封面大图、目录主图或内容页背景底图简约化，复杂底图保留原有主体、层次、材质和细节。
8. **紧密排版要求**：独立强调分组紧凑、有效空间服务文字与图片，避免画面松散却压缩正文空间。
9. **创意要求**：独立写明本页创意手法及其内容用途，实际分块与元素继续在排版树中详细展开。

10. **可读性要求**：单独强调文字清晰、层级分明、对比充分，并优先保障正文空间。
11. **视觉关系要求**：单独强调分组、连接、箭头与图文对应反映真实关系，不为了创意改变内容逻辑。
12. **原图保真要求**：单独强调事实原件不重画、不拉伸，保留主体与关键信息；无事实原件时明确不适用，仍保留底图已确认视觉内容。

## 紧凑排版、创意与学术答辩风格

“简约要求”只约束文本框的填充、描边和框内装饰，不约束三类AI底图的复杂度；新生成和图生图修改都不得仅为满足该条而简化原底图。复杂底图影响文字阅读时，优先通过干净的文本框承载、局部遮罩或位置调整改善对比，保护原底图主体与整体视觉信息。学术答辩的专业气质也不等于把复杂底图改为简单色块。

每页提示词必须把“简约要求”“紧密排版要求”“创意要求”分别写为三个独立的Markdown顶层列表项，不能只藏在内容要求、风格说明或排版树里。三个条目明确强调画面目标，排版树记录具体实现；不要重复抄写整棵树。阶段2.1／2.2的新生成与图生图修订均适用。

- **紧凑排版与文字空间**：在独立的“紧密排版要求”中明确画面紧凑、分组清楚、有效空间集中用于文字和相关图片；根据实际文案体量分配区域，给正文足够宽度与排布空间，保证投影阅读清晰。不能一边保留无用途的大块空白或让装饰、主视觉占据过多空间，一边压窄文字区域、把正文缩得过小。保留必要的内边距、组间间距和阅读留白；紧凑不等于拥挤。空间不足时先调整分块、图文比例和装饰范围，不靠缩小文字解决，也不擅自删改定稿文案。提示词只描述相对层级与空间关系，不写具体字号、框尺寸或密度阈值。
- **有内容依据的创意设计**：在独立的“创意要求”中具体说明本页的创意来自哪种分区组合、图文关系、主题图形或阅读路径，以及如何服务真实内容关系；不能只写“有创意”。积极采用适合本页的特殊分块和组合，继续满足全篇特殊分块页数严格过半的既有要求。创意以内容逻辑和可读性为先，不以无关装饰、特效堆叠或挤压文字空间代替设计。
- **学术答辩的条件性风格**：需求确认属于学术答辩时，在独立的“简约要求”中明确“简约学术”，并在风格说明中保持一致，通过清楚的信息层级、克制配色、准确图表与有组织的构图表达创意。文本框色块保持干净，优先均匀平整的填充、清楚边缘和适度背景色差；框内不叠加纹理、颗粒、污渍、复杂渐变、强烈高光或繁复图案。文本框的层次效果保持轻微，不污染框内阅读区域；底图主体、材质与细节保持原有复杂度，文字阅读通过框底承载或位置安排保障。不因要求风格描述详细而增加特效，不因简约而牺牲内容组织与版式创意。其他用途按已确认风格处理，不一律改为学术风格。

可按本页实际方案使用的提示词措辞：

```markdown
- **简约要求**：简约仅针对文本框：色块干净、边缘清楚、框内装饰克制；封面、目录和内容页三类底图保留原有主体、层次与细节，复杂底图不做简约化。
- **紧密排版要求**：分组紧凑有序，减少无用途留白，给文字足够宽度与空间，不以缩小正文换取松散构图。
- **创意要求**：通过本页实际选定的分区组合、图文呼应或主题结构体现创意，具体做法在下方排版树中展开；不靠特效堆叠或挤压文字实现。
- **可读性要求**：文字层级清楚、对比充分，正文空间充足；复杂底图通过干净框底和位置安排保障阅读，不为构图或装饰缩小文字。
- **视觉关系要求**：分组、箭头及图文对应准确表达真实内容关系，阅读顺序明确；不为创意制造错误因果或错误归属。
- **原图保真要求**：事实照片和数据图不交给模型重画，不拉伸、不替换为近似图；本地等比插入并保留关键主体、坐标轴、图例和单位。无事实原图时说明不适用，底图仍保留已确认主体与细节。
```

上述示例只演示六项独立强调的措辞；完整提示词仍须包含十二项要求和实际嵌套分块树。生成后逐页检查是否存在“画面松散但文字拥挤或过小”、创意描述未落实、学术答辩文本框色块不干净等问题，针对具体问题修订。可读性优先，不新增纯审美数值否决条件。

## 可读性、视觉关系与原图保真的独立强调

每页提示词还必须独立填写“可读性要求”“视觉关系要求”“原图保真要求”三个Markdown顶层列表项，不能仅在内容要求或排版树中顺带提及。与简约、紧密排版和创意一起构成六项独立强调；每项保持简短可执行，不抄写整份规范。

- **可读性优先**：复杂底图可以保留复杂度；以干净文本框、局部承载和位置安排保证文字清楚，不以简化底图或缩小正文作为默认办法。紧凑与创意不能牺牲对比、层级及投影阅读，必要留白保留。
- **视觉关系准确**：对应当前页实际的并列、因果、递进或流程关系说明分组与阅读顺序；箭头仅连接有依据的对象，图片紧邻所支持的内容，不能引入虚假关系。没有连接需求时不强加箭头。
- **原图保真**：阶段2.1按页型处理底图和占位，阶段2.2在批准前本地插入登记事实原件，不把事实图交给模型重画。不拉伸，不生成替代证据；允许按已确认计划适配或遮罩边缘，但主体、图中文字、坐标轴、图例、单位和关键细节完整。无事实原件时该条明确说明不适用，不要求创建占位框或虚构证据；封面／目录继续在原底图基础上构建，不新增底图图注。

生成前校验只检查独立条目与非空说明，不能自动证明清晰度、关系准确或实际保真；生成后逐页实际查看并核对设计稿和登记原件。

## Markdown 嵌套列表与实际分块树

阶段2.1／2.2的新生成和图生图修订提示词必须使用 Markdown 语法，十二项要求作为顶层列表项；“排版要求”内部用缩进子列表表达画面实际的空间归属：**宏观分块 → 微观子分块 → 更深层子分块（实际存在时继续嵌套）→ 文字及其文本框、图片、装饰等具体元素**。同级列表表示并列区域或并列对象，子列表表示属于其父分块，不能把空间层级写成一串平级说明或仅列素材类别。

- 每个分块先说明位置、边界形态、所承载内容、与相邻分块的关系及阅读顺序，再嵌套它的子分块和元素。嵌套深度由实际版式决定；已有子分块必须展开，不为凑层数虚构分区。
- 每段文字及其文本框放在实际所属的最内层分块下，用一个元素条目关联二者，再用子项写文案、语义角色、框形、填充／描边、对齐、相对大小及装饰。无可见框体也明确说明；并列段落各为独立条目和独立文本框。
- 图片、图标、装饰和编号底座放在实际所属分块下，逐项写内容、形态、样式、叠放和邻接关系。框内装饰归入对应文本框，不把它与整页装饰混列；跨分块箭头或装饰归入共同父分块，写清覆盖区、连接对象和前后层次。
- “内容要求”写页面语义与阅读目标；完整文案在排版树的对应文字条目中逐段出现，不必另抄一次平级清单。“底图与配图要求／图片占位框比例”集中说明底图或原件处理规则；具体图片位仍嵌套在所属分块中。“风格要求”描述共用视觉语言，具体对象的局部差异写在对象条目中。
- 使用空格缩进，按 Markdown 列表层级对齐；API 的 prompt 字符串保留真实换行和缩进，不压成单行。不把整个提示词包在代码围栏里；本文件示例的围栏仅用于展示写法。分块名和元素名使用内容名称与位置描述，不写内部编号、具体坐标、文本框尺寸或字号。

示例（结构演示，按本页设计稿替换内容和分块）：

```markdown
- **简约要求**：简约仅针对文本框：色块干净、边缘清楚、框内装饰克制；封面、目录和内容页三类底图保留原有主体、层次与细节，复杂底图不做简约化。
- **紧密排版要求**：分组紧凑有序，减少无用途留白，给文字足够宽度与空间，不以缩小正文换取松散构图。
- **创意要求**：通过本页实际选定的分区组合、图文呼应或主题结构体现创意，具体做法在下方排版树中展开；不靠特效堆叠或挤压文字实现。
- **可读性要求**：文字层级清楚、对比充分，正文空间充足；复杂底图通过干净框底和位置安排保障阅读，不为构图或装饰缩小文字。
- **视觉关系要求**：分组、箭头及图文对应准确表达真实内容关系，阅读顺序明确；不为创意制造错误因果或错误归属。
- **原图保真要求**：事实照片和数据图不交给模型重画，不拉伸、不替换为近似图；本地等比插入并保留关键主体、坐标轴、图例和单位。无事实原图时说明不适用，底图仍保留已确认主体与细节。
- **比例要求**：内容页，16:9（1920×1080）。
- **内容要求**：先说明研究方法，再展示结果，最后总结结论。
- **排版要求**：上方标题区，下方左侧方法区与右侧证据区；由上到下、由左到右阅读。
  - **上方标题区**：保持清晰阅读背景。
    - **标题文字及其文本框**：无可见框体，左对齐。
      - 文案与角色：“研究方法与结果”，页面标题。
  - **下方主体分块**：方法区与证据区以间距和色面区分。
    - **左侧方法分块**：两段文字上下并列，样式一致。
      - **上部方法子分块**：说明数据处理。
        - **文字及其独立文本框**：圆角矩形，浅蓝填充，与局部深蓝背景形成适度色差；细青色描边，框高贴合正文。
          - 文案与角色：“统一数据口径后开展比较。”，正文。
          - 框内装饰：左上角小圆点，与文字留出间距。
      - **下部方法子分块**：说明验证。
        - **文字及其独立文本框**：沿用上部框样式。
          - 文案与角色：“通过独立样本检验结果。”，正文。
    - **右侧证据分块**：图片在上，说明在下。
      - **上部图片区**：实验结果图，图片位比例4:3；画与背景可区分的无字占位块，按此比例画，不拉伸、不变形。
      - **下部说明区**：无可见框体，紧随图片，保持清楚间距。
        - 文案与角色：“结果对比”，图注。
    - **跨区连接箭头**：由方法区指向证据区，表达验证关系，置于两区间隙，不穿过文字。
- **图片占位框比例**：事实图仅预留占位块；完整预览批准前在本地插入登记原图。
- **风格要求**：沿用所给大图的深蓝与青蓝同一套配色；背景渐变与细微主题纹理集中于外缘，文字区平静；卡片以柔和阴影分层，标题字重突出，正文清楚稳定。
- **进度条要求**：按本页已确认导航写全小节标题，突出当前小节。
```

生成前脚本检查 Markdown 列表和“排版要求”的嵌套结构，识别加粗项名；不能自动证明空间归属正确、所有微观分块已展开或元素完整。编写者仍须对照设计稿检查分块树，生成后逐页确认实际画面。

## 全部文本框与图形元素的逐项说明

生成页面预览时，不能只写“按设计稿排版”或概括几个大分区。提取当前页所有可见元素，按分区与阅读顺序逐项写清，统一样式可先描述一次，但每个对象的内容、位置关系和独立性都须保留：

- **每个文本框**：实际文字、语义角色、所属分区、大致方位和邻接关系、形状或无可见外框、填充与描边、对齐、相对大小、前后层次、内边距和框高适配；采用阴影、渐变、框内图标或装饰时一并写清。并列段落逐段说明独立文本框，同组概括性小标题及各框小标题按设计稿带入，不能合并成一个大框。
- **每个其他图形元素**：说明形态和用途、颜色／填充／描边、方向或曲率、相对大小、大致位置及与文字、图片或其他图形的关系；需要叠放、贴合、遮罩或出血时写清。覆盖主视觉、图标、圆环、节点、装饰纹样、分区色块、编号底座及导航分段，不用“若干装饰”代替设计稿已经规划的对象。
- **箭头和连接线**：逐条写连接的真实内容名称、起止对象、方向、路径走向和连接作用；不使用内部元素编号，也不凭装饰引入错误因果。
- **分区与图片位**：用文字说明实际分区数量、边界走向、嵌套或组合、阅读顺序及色差／间距；每处配图说明内容、图片位比例和位置。其他页型的事实图片按登记原件等比占位与本地插入；封面／目录按原底图构建契约，不要求占位框；不让模型重画事实图。

若同类装饰形成规则阵列，可按一组描述数量或排列模式、成员形态与覆盖区域，不必给每个点单独起名；关键独立对象仍逐项说明。这些是语义和相对关系描述，不写具体坐标、文本框尺寸或字号；内部编号只留在本地元数据。风格参考图不能代替上述元素描述，生成后按设计稿逐项实际看图检查遗漏、误合并和样式偏差。

## 风格说明的具体程度

风格说明可以简略，通常用2–4句或几个短子项即可；这是写作建议，不设句数限制。写清本页实际需要的视觉特征，不必逐项展开材质、光影、纹理和字体细节。

- **主要信息**：整体气质、主辅配色及用途、背景与文本框的处理。字体只说明有必要区分的层级或字重，具体对象的样式继续放在排版树中，不重复抄写。
- **继承与差异**：沿用已确认方向时，简短说明继承的配色和视觉语言，再写本页实际差异；保留足以执行的关键信息，不只写“同风格”或“高级”。每次提交的提示词仍应自足，不假设模型能读取本地全篇约定。
- **可选效果**：仅在本页实际采用时补充材质、光影或主题装饰；允许无装饰、平整色面和克制处理，不为写详细而增加特效。学术答辩仍须明确简约学术、文本框色块干净。

示例：

> 风格要求：沿用所给底图的深蓝与青蓝同一套配色，采用简约学术风格。背景平静，文本框为干净平整的浅蓝色块，与背景有适度色差；标题字重突出，正文清晰。保留原底图主题细节与复杂度，以干净框底承载正文并保障阅读空间。

生成后若层级、主题表达或构图创意不足，针对缺失的分组、图文关系或主题特征补充描述；不因说明较短或画面克制而反复生图，不靠装饰堆叠替代设计。

## 内部编号不进入提示词

所有生图阶段的新生成与图生图修订提示词均不得包含内部页面、文本、图片、素材、参考页或任务编号，例如 S01、S03-BODY-01、GEN-001、RECON-001 等。即使附上“不要画编号”的否定句，也不要把实际编号写进提示词。不得把设计稿表格、元素清单、带编号的标题或素材文件名原样拼接给模型。

按“左侧问题卡片”“右侧实验结果图”“方法概览小标题”等内容名称、位置和语义角色描述元素；箭头用内容短语说明连接关系。内部编号与描述的映射保留在本地 JSON、提示词记录的元数据栏和账本中，与实际发送的 prompt 正文分开。整页任务用 page_id 绑定页面；兼容从任务 id 解析页面，不能再从提示词解析页面。

占位块默认无文字，需要文字时只用内容说明。用户确认的目录序号、步骤序号、公式编号、产品型号或样本名称属于实际内容，按定稿保留；不要把内部工程标签当作这些上屏内容。

生成前自检发现内部编号时直接退回提示词，先人工改成内容描述再提交，不静默删除，以免损坏科学内容或箭头逻辑。

## 禁写信息

**禁止在提示词中写元素具体坐标、文本框具体尺寸和字号**，包括 x／y、固定框宽高、像素位置与归一化坐标。画布尺寸、图片位比例和科学内容中的数字可以保留；字号仅留在设计稿，精确几何与轮廓点留在图片计划和重建规格。新生成与图生图修订同样遵守。

不写检查码、规则编号、审美阈值、机检条文或整份设计稿；每次只提取当前页。事实边界写进任务字段 factual_boundary，不堆成提示词长段。

## 参考图与素材

- 封面和目录使用该方向已确认原底图（hero-image／toc-image 或已登记替代底图），在原底图上构建；content／thanks 可参考 content-background，参考不意味着必须铺进成品，其背景形式与主视觉位置以设计稿为准。
- 生成页面预览时不提供分块参考图，也不要求复制分块图或建立 split-references.json；参考库仅供设计阶段本地查阅。分区形态和全部文本框／图形元素改由提示词详细说明，具体口径见生图提示词规范。风格参考、获准材料及图生图返工原页仍按各自用途提供，不能与分块示意图混淆。
- 可用已生成预览作内部参考；旧稿、照片等外部材料须登记并获准上传，数量遵守 referenceImageLimit。需要编辑事实图时在本地处理，不交给模型重画。
- 装饰、图标和说明插画只提供已登记且实际采用项，在提示词中写内容名称、用途和插入方式，编号仅留在本地任务元数据；不为填满留白加图。

## 生成与修订

先dry-run自检供应商、任务与提示词，再execute；生成器检查十二项结构及六个独立强调项、画布规格、部分内容／框形／比例／风格／导航描述与元数据一致性，不能自动证明所有对象均已描述或实际绘制。编写者须逐项对照设计稿检查元素描述完整，生成后逐页核对画面落实。每次生成后逐页看图，按设计判断检查逻辑、可读性与一致性。

返工把被退回的原页放入 references 或 edit_source，逐条写明保留什么、改什么，在原图基础上图生图修改；保留编辑谱系与哈希，不另起无来源的新图绕过返工。2.2 修订完成后重新本地插入登记原件并复看。

提示词全文统一登记在 generation-prompts.md；任务、API 返回、原始／规范化输出和采用／淘汰记录走对应阶段账本。尺寸、文件身份和来源证据按[预览契约](../../../shared/preview-contract.md)核验。
