# 非文字元素识别清单（阶段 3.1 第一步）

在编写逐元素清单 `slide-elements.md` 之前，先逐页识别已批准预览里**除文字之外的所有元素**：装饰性线条、线阵、点阵、圆环、圆弧、色块、分色、图形、图标、渐变与光影、材质纹理都要列到，一个都不能漏。

- **计划图片只按占位块记录**（写明“这里要放计划图片 `Sxx-PHOTO-01`”即可）：占位块本身不拆、不抠、不重绘，真图在阶段 3.3 按 `image-plan.json` 插入。
- 每个元素写清**大致位置**：所在分块／方位，以及归一化框 `x`／`y`／`w`／`h`（0–1，可给近似值），并写明它服务于哪段文字、哪个文本框或哪张图片。
- 每个元素写清**计划的分离方式**：`ai抠图`／`svg重绘`／`原生组装`。**形状或颜色复杂**（有机形状、复杂纹样、渐变、光影材质）→ 用前两种；**形状与颜色简单**（规则几何、纯色、直线、简单箭头）→ 用原生组装；并写一句理由。
- 阶段 3.2 按本清单**逐个**还原元素，不得遗漏或简化；还原后的形状、颜色、渐变与视觉效果必须与已批准预览一致。
