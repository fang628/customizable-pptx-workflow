# 设计判断与检查提示

本文件是各阶段设计决策的统一依据。设计稿记录本项目的选择，不复制整份规范；阶段文件只补充各自的操作要求。用户明确要求优先于默认建议，事实准确、原件身份与交付可编辑性仍须保持。

## 优先顺序

1. **事实与表达准确**：保留必要条件、比较口径、证据和结论，视觉关系不得暗示不存在的因果或层级。
2. **内容逻辑与可读性**：先确定主要观点、证据组织、阅读顺序和文字层级；正文、图表与关键信息清楚可读，不能用装饰或高密度目标牺牲阅读。
3. **跨页一致与空间组织**：统一对齐、间距、配色语义与导航；同类内容可以复用同一版式。
4. **视觉表现与装饰**：在前三项满足后选择分块形态、框形、主视觉、背景与特效。

冲突时按以上顺序取舍。信息多时先精简赘述、重新分组或拆页；留白合理时保留，不用缩小字号、增加框形或补图来凑密度。

## 用户明确要求与条件性设计建议

特殊分块严格过半、每页有相关配图、并列段落拆分为独立可编辑文本框属于用户明确要求；整组小标题、具体分块形态、框形与特效等按下文条件选择。

- **分块**：先判断流程、对比、层级、并列或中心与支撑关系。在符合内容逻辑、保持可读性的前提下，使用特殊分块的页面数必须严格大于全篇正式总页数的一半，并尽可能多使用；适配时优先采用特殊分块，让尽可能多的页面使用有助于表达的特殊形态。逐页说明形态如何服务内容关系；不能为增加数量而暗示不存在的层级、因果或中心关系，也不能牺牲阅读。常规分块更适合内容时可保留，但整套须满足特殊分块页数过半。总页数 N 取 content.json 的全部正式页面（含封面、目录、章节页、内容页与致谢页），最少需 floor(N/2)+1 页；同一页采用多种特殊分块仍只计一页，横带与四宫格不计作特殊分块，单纯装饰背景也不计。特殊分块参考图仅作结构启发，不要求严格按照参考图生成页面；可按内容关系、文字体量和阅读顺序调整分区数量、比例、方向、曲率、顶点／圆心位置及组合方式。以本页设计稿的实际选择为准，不照抄参考图的黑线、粗边框或具体几何。积极使用斜切、弧线以外的创意特殊分块，不把这两种作为默认重复方案。结合内容主动探索扇形、同心圆、波浪、金字塔、圆形放射、左圆右栏、六边形／蜂窝及它们的变体或组合。整套复核时检查是否过度依赖斜切和弧线，对适合其他形态的页面主动改进；变化应来自内容关系与空间组织，不靠换色、镜像或堆装饰凑数。同类内容可复用有效结构，不设各形态的固定数量配额。
- **文本框**：由语义分组和阅读需要决定是否套框。长正文通常适合矩形或无框排布；短标签可采用胶囊、圆形等。全篇复用矩形或圆角矩形是合理选择，不强求不同层级换形状。同级并列保持一致；装饰可省略。并列文本框可按内容需要采用“小标题＋正文”结构：每个框的小标题概括该框内容，同组小标题的层级、位置、对齐和样式一致，正文与小标题有清楚的层级差异；无助于理解时可省略小标题。框内小标题不同于整组的分区标题，不要求每组同时具备两者。
- **要点**：多段并列文字必须在设计稿中逐段拆成子列表，每段对应独立的可编辑文本框，不能把全部并列段落放进一个文本框；同组样式一致。多段并列文字推荐设置一个概括整组共同主题或结论的小标题，通常放在该组上方或阅读起点，与各段正文有清楚的层级差异；标题应准确、简短，已有分区标题能概括整组时可直接复用，无助于理解或重复时可省略。这是建议，不是强制要求；各段仍分别使用独立文本框。子列表表示排版条目，不额外暗示内容层级；单段文字内部的连续说明可以保留在该段文本框内。
- **配图**：每一页都必须有至少一处与本页内容相关、清晰可辨的配图，包括封面、目录、章节页、内容页和致谢页。可用登记照片、数据图、图表、机理图、示意图或主题主视觉；单纯底色、纹理、分区色块、边框与导航装饰不算配图。优先采用登记原件；缺少非事实性机理图、示意图或主题图时可生成补充，事实图片缺口必须登记，不能生图伪造证据。配图应服务内容并保持可读性，不为有图而堆放无关素材。
- **主视觉**：按标题长度、阅读方向和主题安排左、右、中央或通栏构图。标题在左时可采用“主体偏右、左侧干净”；标题在右时可镜像，短标题也可居中。平面、摄影感或 3D 表现按主题选择，不固定为现实 3D。
- **背景与素材**：成组大图是候选和风格参考，不因生成过就必须进入成品。背景可用原生纯色、渐变或已登记且实际采用的图像。封面、目录和内容页按表达需要采用对应候选图；只重建已批准画面采用的素材。补充图标或插画要有用途，避免零碎堆砌。
- **边缘处理**：照片、截图和数据图可保留矩形原边，保证信息完整；独立主体需要融入背景时再抠边、羽化或套遮罩。边界贴合、弧形排列和装饰位置是可选手法，不得妨碍文字与事实图阅读。
- **框高与底色**：框高以内容和分组关系为准；短文本通常不需要高框，比较卡片为保持共同尺度可以等高。采用有填充的文本框时，框底与所在区域的实际背景应有可辨认的适度色差，让框体层次清楚；这里比较填充色而非描边色，不能只靠描边代替框底色差。优先用协调的邻近色或明度变化，复杂背景按框所在区域判断，不以整页平均色代替。填充色、描边色分别记录，不设固定色差阈值；需要更强色差才能清楚分组时允许使用，文字对比和可读性优先。无填充或无框文字按文字与背景的可读性检查。

较充分的信息密度、页内逻辑与可选文字配色建议按[信息密度与文字配色](content-density-and-text-color.md)执行，用户明确风格可覆盖默认值。

## 数值只用于触发复看

以下是诊断起点，不是版式通过条件。命中提示时检查真实画面：是否内容不足、阅读受阻、主体被裁、背景干扰或层级不清。合理的留白、图文比例、字号与配色可以保留，在现有 review／qa-review.json 的 notes 中简述依据；无需为偏离建议数值另行申请批准，也不按警告数量自动否决。

| 检查主题 | 参考起点 | 复看重点 |
|---|---|---|
| 内容区占比 | 宽约 72%、高约 62%、面积约 45% | 是否充分支持本页观点；封面、章节页、单结论页可更疏朗 |
| 连续留白 | 约 18%–28% 或多个空白分区 | 是否帮助分组、突出结论，而非遗漏内容 |
| 主视觉占比 | 封面约 20%–60%；目录约 10% | 主体是否清楚、文字是否有足够空间；目录页也必须有与主题相关的配图 |
| 背景不透明度与反差 | opacity 约 0.10–0.35、反差约 10%–35%、阅读区较干净 | 以文字与图表可读为准；不要求固定中心空区 |
| 段落长度 | 约 110 字／7 行；180 字／10 行以上重点复看 | 优先精简、分组或拆页；不因字数单独判失败 |
| 字号与层级 | 正文约 18 pt；标题、目录按观看距离放大 | 依据投影、屏幕或阅读用途实际检查；文字溢出、不可读仍需修复 |
| 裁剪、装饰与导航尺寸 | 参考页与 qa_rules.py 中的比例 | 主体、数据、文字与导航是否完整；几何风格不靠数值判美观 |
| 同风格主色距离 | qa_rules.py 的配色距离阈值 | 是否仍保留配色语义与跨页一致性；浅深页、事实图可有合理差异 |

特殊分块最少页数floor(N/2)+1及占位框默认12%／满足修订记录条件后15%的比例容差属于既定约束，不由审美复看提示覆盖；后者仅按[有限放宽规则](preview-contract.md#多次比例修订后的有限放宽)执行。

16:9／1920×1080 输出规格、图片不得拉伸、文件哈希、材料身份、准确文字、对象完整性与批准状态属于技术和真实性约束，仍按各自契约检查，不属于上述审美提示。
