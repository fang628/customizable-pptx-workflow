# 分步执行与读取范围

每个阶段入口只用于路由。按入口顺序读取一个子步骤，完成其工件后再读取下一个；不要预加载全部子步骤、共享规范、模板和参考库。

## 一次读取的范围

- 一次读取一个操作步骤和它实际需要的共享章节；共享文档先查标题，再选章节，不读取全文。
- 单次返回以 12000 字符为上限，优先控制在 6000 字符内。这是上下文管理目标，不是内容验收标准；超限时继续按子章节或页面拆分，不截断规范。
- 材料按文件和页段逐批读取，登记已读取范围与提取结果，最终仍须覆盖全部材料。设计稿、提示词、元素识别及审阅按 1–3 页小批次处理；总览另检查叙事、页序与全篇风格。
- 模板仅在建立对应工件或变更格式时读取；风格、页型、分块库仅取本轮采用的条目。

## 规范复核与版本

保留阶段入口、写稿前、提示词编写前的三个复核时点。当前会话已读取且版本未变的同一规范片段可沿用；先核对文件 SHA-256 与本轮实际适用范围。进入新子步骤补读新增规则；规范、需求或对应页内容改变时，重读受影响片段。脚本校验不能替代首次阅读或变化后的复核。

## 按章节与页面读取

```powershell
python <skill>/shared/scripts/read_context.py <skill>/shared/operations.md --list
python <skill>/shared/scripts/read_context.py <skill>/shared/operations.md --section "独立素材生图任务"
python <skill>/shared/scripts/read_context.py <project>/02_design/design-spec.md --page S03
```

工具忽略代码围栏中的示例标题；目录输出文件与章节 SHA-256，可用于核对已读片段版本。超过上限会报错，提示继续拆分，不输出截断正文。各子步骤中的链接只说明需要查哪一条规则，不意味着打开链接文件全文。

## 连续执行与恢复

子步骤编号不新增工作流阶段或用户闸门。仍只有 1.1、1.3、2.1、2.2 可停下来等待用户。每完成一个子步骤可执行 `workflow.py <project> checkpoint <stage> --step <子步骤编号>`；检查点仅保存当前位置，不构成批准，也不结束任务。中断后检查工件和依赖，从失效的最早子步骤继续。
